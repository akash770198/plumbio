# AquaFix Plumbing — Next.js

Service-industry homepage built with **Next.js**, **Tailwind CSS**, and content loaded from JSON.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Data

All copy and image paths live in:

- `src/data/site.json`

Imported via `src/data/index.ts` and used across page sections.

Images are served from `public/img/`.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — serve production build
